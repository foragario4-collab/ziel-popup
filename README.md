# Ziel-Popup – Testversion (Phase 1)

Adresse eintippen → die App prüft über OpenStreetMap, was an der Adresse bzw. in der Gasse ist,
und zeigt nur offene Orte (oder unbekannte Zeiten) als Popup an. Keine Google-Dienste.

- Mit Hausnummer: genaue Adresse + Umkreis 25 m
- Ohne Hausnummer: ganze Gasse
- Geschlossene Orte werden ausgeblendet

Die APK wird bei jedem Hochladen automatisch von GitHub gebaut (Reiter „Actions“)
und unter „Releases“ zum Download bereitgestellt.
